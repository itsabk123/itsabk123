## 3. Defects found and fixed during QA

| # | Severity | Defect | Evidence | Fix | Retest |
|---|---|---|---|---|---|
| 1 | High | Layout variable `$cur` in header overwrote the report's currency → percentile table printed "report.php 136,180" | Dark-mode screenshot of Monte Carlo section | Renamed to `$curPage`; regression test asserts no "report.php <digit>" | Pass |
| 2 | Medium | Hedonic model extrapolated on comparable distance (subject distance 0 outside sample range) → 6% bias | Engine test "hedonic recovers value" failed | Removed distance from hedonic regressors (it is a weighting factor, not a property attribute) | Pass |
| 3 | Medium | Required selects with defaults (property type) raised "required" errors when blank | Engine test | Required check only for truly missing values | Pass |
| 4 | Medium | Mobile overflow: grids used `1fr` (min-content) so wide tables widened the page; unbreakable JSON on methodology | Playwright overflow 411–436 px | `minmax(0,1fr)`, `min-width:0`, readable scenario text, wrap safeguards | Pass |
| 5 | Low | Desktop showed "Menu" toggle and wrapped nav; button labels wrapped | Desktop screenshot | Selector specificity + `white-space:nowrap`; collapse below 1120 px | Pass |
| 6 | Low | `button.btn` specificity overrode ghost/small variants | Screenshot | Removed element-qualified selector | Pass |
